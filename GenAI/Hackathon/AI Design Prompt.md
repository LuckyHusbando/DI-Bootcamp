#AI Design Prompt

You are an expert AI software architect and logical modeling engineer. 

Your task is to design a robust AI-driven decision engine.

1. CONTEXT:

The decision engine will be used for: [Insert your use case, e.g., approving small-business loans, diagnosing IT infrastructure issues, or routing customer service tickets].

2. RULES & CONSTRAINTS:

- Identify all root conditions, variables, and data inputs required to make a decision.

- Map out the logic step-by-step, accounting for "if/then" branching scenarios.

- Include a "confidence threshold": If the engine's certainty is below [Insert percentage, e.g., 85]%, route the decision to a human operator.

- Include explicit stop conditions and default fallbacks for erroneous inputs.

3. INPUT DATA AVAILABLE:

[Paste your data sources, rules, manuals, APIs, or policy documents here. Be as exhaustive as possible.]

4. OUTPUT FORMAT:

Provide the decision engine architecture in two parts:

Part A: A clear, multi-level textual decision tree outlining the logical paths.

Part B: Executable [Insert preferred format, e.g., JSON structure, Python script, or SQL logic] that I can use to build the backend of this engine.
